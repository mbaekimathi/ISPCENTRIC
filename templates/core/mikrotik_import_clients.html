How it works

Anyone can import — even from another billing system. You do not need perfect column names.

1. Start with a file

Download our template, or use any Excel/CSV export (old system, MikroTik list, Google Sheet download, etc.).

2. We guess the columns

ISPCENTRIC auto-matches common headers like Name, Phone, Package, Router. You can fix any mismatch.

3. Fill the gaps

If your file has no MikroTik or Package column, pick defaults once — they apply to every row missing that value.

4. Safe defaults

Missing passwords and account numbers are generated. New clients start as queued for install unless Status says active.

  • Required: Full name + Phone (every row).
  • Package & MikroTik: in the file, or chosen as defaults below.
  • Duplicates: same phone or PPPoE username in this ISP is skipped with an error.
  • Limit: up to 2,000 rows per upload.
